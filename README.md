# My Website

My personal website — a small hand-built homepage with an *About me*
page and my photography.

## What's inside

- **Home** (`index.html`) — welcome page and introduction
- **About me** (`aboutme.html`) — more about me, my photographs and my
  university (Boston University)
- **Custom cursor** — a mouse effect built with the script and styles
  in `Mouse/`
- **Custom typography** — display fonts (Monoton, Special Elite and
  others) kept in `Font/`

## Tech

Plain HTML, CSS and JavaScript — no framework, no build step.

## Run it

Open `index.html` in a browser, or serve the folder with any static
server, e.g.:

    npx serve .

## Structure

    index.html     homepage
    aboutme.html   about me / photography
    css/           page styles
    js/            page scripts
    Font/          font files
    Mouse/         custom cursor effect
